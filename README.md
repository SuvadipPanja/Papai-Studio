## About

A cinematic portfolio for Papai Studio — weddings, Haldi, rice ceremony, pre-wedding shoots and drone coverage. The goal was simple: let the photos speak, load fast on a phone, and help new couples find the studio on Google.

## Features

- Full-screen gallery sections for each type of shoot
- Mobile-first layout that feels smooth on slow connections
- Optimised, cropped images (custom `crop.mjs` script)
- SEO basics done properly: meta tags, `sitemap.xml`, `robots.txt`
- Deployed on Vercel

## Run locally

```bash
npm install
npm run dev
```
